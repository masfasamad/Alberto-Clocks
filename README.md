# Alberto Clocks Website

## Project Overview
This project is a responsive Single Page Application (SPA) developed for Alberto Clocks, a luxury watch and retail company. The website is designed to showcase the brand’s products, categories, technology, services, and contact information in an attractive and user-friendly format.

The goal of this project is to create a professional business website using front-end web technologies and apply the concepts learned in HTML, CSS, and JavaScript in a practical environment.

---

## Objective
The main objective of this project is to build a modern and responsive website for a real-world business scenario. The website should help users explore watch categories, view product details, check pricing, browse the gallery, and contact the company with ease.

This project aims to:
- apply front-end development concepts practically
- improve UI/UX design skills
- create a user-friendly interface
- build a responsive website for different screen sizes
- present a professional business brand online

---

## Problem Statement
Alberto Clocks is a full-service watch repair, appraisal, and retail store offering premium luxury timepieces from well-known brands. The company wants a modern website that reflects its premium identity and helps customers learn more about the products and services offered.

The website must be designed to:
- work efficiently across major browsers
- display attractive product sections
- provide watch information in an organized way
- include product categories such as Vintage, Luxury, and Smart Watches
- display product details in a popup window
- include a pricing section and gallery
- provide About Us and Contact Us details

---

## Features
- Responsive navigation menu
- Professional logo placement
- Attractive color scheme and layout
- Product categories such as Vintage, Luxury, and Smart Watches
- Product listing for each category
- Popup modal for watch details
- Price list section
- Image gallery
- About Us section
- Contact Us section with email, address, and phone number
- Visitor count section
- Date, time, and location ticker
- Hover effects and fade animations
- User-friendly design for desktop and mobile devices

---

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## How to Run
1. Download or clone the project folder.
2. Open the `index.html` file in your browser.
3. The website will load and display the homepage.
